# Checkpoints anteriores à correção de persistência

de gravação `WinError 5` no Windows. Cada coleta parou após 76 GETs, antes da
fase exposure, com quatro alvos pendentes. O status antigo `completed` não
representa uma execução concluída; essa inconsistência foi corrigida.

Os comandos foram repetidos após a correção. Os resultados válidos estão em
[`../three-modules.json`](../three-modules.json) e
[`../budget-84.json`](../budget-84.json). Consulte também
[`../summary.json`](../summary.json) e o
